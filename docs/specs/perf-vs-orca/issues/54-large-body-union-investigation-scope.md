  do not silently reuse retired output references. Stop on drift, missing input
  or an unqualified identity/freshness gate; no automatic retry or threshold
  relaxation.
- Preserve checkout-usable evidence and a falsifiable reducer/verifier; remove
  probes and restore sources/artifacts, verifying identities and both freshness
  gates. Return a concrete, evidence-backed candidate recommendation or a
  falsified lead, with gaps. No KEEP, commit, adoption retry, default switch or

# Packet Contract: 231-guest-closure-fingerprint

## Goal

Replace the hardcoded shared-crate fingerprint set in `xtask/src/build_guests.rs` with a per-guest dependency-closure walk over manifest path deps, delete the now-unreachable `compute_shared_freshness` and `stage_wit_snapshot`, make `xtask/src/test.rs`'s pnp_cli freshness an unconditional `cargo build --bin pnp_cli`, and re-align `crates/pnp-cli-locator`'s documented `is_stale` mirror with the model that replaces it.

## Scope Boundaries

This packet owns the guest fingerprint **input set** and its plumbing: the closure walk and its cache, the deletion of `shared_input_paths` / `compute_shared_freshness` / `stage_wit_snapshot`, the resulting signature changes on `compute_guest_freshness` / `is_stale` / packet 230's `CheckContext`, and the unconditional pnp_cli rebuild in `xtask/src/test.rs`. It also owns the ADR-0054 conformance obligation that this model change creates for `crates/pnp-cli-locator::staleness_reason`'s rustdoc mirror. It does **not** change artifact decoding, stage resolution, drift comparison, the `v2-` fingerprint hash content or lifecycle, or the exit-code contract — those are packets 229 and 230 — and it edits no documentation prose beyond the `docs/07` task row and that rustdoc; the freshness-contract doc surface is packet 232.

## Prerequisites and Blockers

- Depends on: `docs/spec_packets/230-output-based-guest-freshness` (`status: draft` at authoring time — this is a **FORWARD-DEP**, not a satisfied dependency), which itself forward-depends on `docs/spec_packets/229-wit-verify-declaration-model`. This packet consumes exactly these items from `xtask/src/build_guests.rs` as packet 230 leaves them: `CheckOutcome`, `check_command`, `build_stale_command`, `StaleReason`, `stale_reason`, `CheckContext`, `EXIT_FRESH` / `EXIT_STALE` / `EXIT_INFRA_ERROR`, and `FINGERPRINT_VERSION = "v2"`. It also relies on packet 230 KEEPING `GuestSpec.stage_id` and `parse_stage_id_from_module_manifest` (Round 5 finding R5-4); this packet must not delete either.
- Unblocks: `docs/spec_packets/232-freshness-gate-docs`, which documents the model this packet lands.
- Activation blockers: packets 229 and 230 not yet `status: implemented`.

Implement only after `proptest-openrscad_02_pbt-domains` and its foundation prerequisite are implemented. Recheck their actual feature, public export, runner, profile and artifact shapes on disk. All new test names/features below are planned additions; no authoring-time test, correctness or measurement result is implied. ## Step 3: Prove bounded beading formulas and their falsifiers

Also drive the spec's real factory stack and `populate_beading_propagation` on a valid transition graph; assert its independently derived two-bead side-table output. This proves the count-two case is reached at the real caller, rather than only within a directly called wrapper. Reproduce before fixing; preserve the actual parent transition threshold and all other canonical branches. Check vector alignment and safe arithmetic; add deliberately malformed results to falsify the independent comparator. Include boundary witnesses and preserve the relevant case mode on shrink.
- Verify: `C`; register/pilot the `H-ARACHNE-BEADING` record only once its callback exists and profile is measured, then run its selected registry routine/extended commands through `cargo xtask test` and retain both logs/events.

# Packet Contract: wipe-tower-geometry-keys

Re-authored in place (number and slug retained) with explicit user approval. The prior revision declared 12 keys in the `wipe-tower` manifest and wired one; a later audit (`docs/specs/orca-feature-gap/issues/key-correction-inventory.md`) found **zero** of the 12 read anywhere in the tree, making every one of them a rule-1 declaration-only key. This revision keeps seven keys, each of which drives geometry this packet builds, and returns six to the queue.

## Goal

Give the `wipe-tower` core module a real **tower wall**, a real **footprint rotation**, and a real **purge flow multiplier**, so that seven OrcaSlicer P03 keys drive behaviour instead of sitting in a manifest. `wipe_tower_wall_type` selects among three wall generators the packet builds — `rectangle` (the footprint loop), `cone` (canonical's corner arcs of radius `tan(cone_angle/2) × (tower_top_z − z)`, tapering to nothing at the top), and `rib` (canonical's two thickened diagonals unioned with the footprint, giving four corner arms whose reach comes from `wipe_tower_rib_width` and `wipe_tower_extra_rib_length`) — with `wipe_tower_fillet_wall` rounding the rib junctions. `wipe_tower_rotation_angle` rotates every emitted tower point about the tower origin and moves the bed-bounds check onto the rotated wall. `wipe_tower_extra_flow` becomes the purge lines' effective-width multiplier, preserving purge volume as canonical does.

## Scope Boundaries

In scope: `modules/core-modules/wipe-tower/wipe-tower.toml` (seven new `[config.schema.*]` tables), `modules/core-modules/wipe-tower/src/lib.rs` (`from_config`, `generate_purge_paths`, `run_finalization`'s bed check, plus new wall-polygon, fillet and rotation helpers), the module's test files plus one new test binary, one scheduler bounds arm, one runtime leakage arm, and the generated `docs/15_config_keys_reference.md`.

Out of scope: the six keys listed in `requirements.md` § Returned to Queue; canonical's rib-mode **square-tower re-planning** (`WipeTower::plan_tower_new` — recorded as divergence DIV-1); canonical's gap-wall / skip-point cutting (`construct_gap_for_skip_points`, driven by `prime_tower_skip_points`, which packet `254a` returned to the queue); the prime-tower keys owned by `254a` / `254b`; and — per map Authoring rule 2 — **any** edit to `ORCA_CONFIG_PADDING` (`crates/slicer-gcode/src/serialize.rs`), which carries a hardcoded `wipe_tower_rotation_angle` twin that this packet neither corrects nor removes.

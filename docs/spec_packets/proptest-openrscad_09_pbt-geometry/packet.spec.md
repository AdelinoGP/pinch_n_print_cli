# Independently-oracled geometry and mesh properties

## Goal

Exercise the H-BOOL, H-OFFSET and H-MESH production seams and selected mesh-helper contracts with bounded direct properties, independent geometric references, concrete regressions and measured Windows execution, with scripted enrichment when available.

## Why

The approved `docs/specs/proptest-openrscad-adoption.md` §§5–6, 10 and 12–13 requires set and geometric behavior, not random calls that merely return. Clipper-backed output cannot certify itself through `validate_polygon_simplicity` (`crates/slicer-core/src/polygon_ops.rs`), and scripted output is stimulus, not an expected answer. This packet binds the direct domains and independent predicates planned by #2 to real owning-crate operations, with explicit numeric and topology limits.

This is not a promise that every polygon survives an offset round trip, every smoothing result contains the input, or every point on a clipping boundary is exact. `clip_polylines` deliberately pre-inflates its clip by one integer unit; `slice_mesh_ex` uses sorted Z planes and has a specific vertex-plane convention. The test domain and oracle must account for those actual paths.

## Scope

- In: `union`, `intersection`, `difference`, `xor`, `clip_polylines`, `offset`, `offset2_ex`, `smooth_outward_polygon`, `slice_mesh_ex`, `transform_point3`, `AabbTree` bounds/rays, and `split_connected_components`; direct registry properties, independent controls and deterministic cases; measured routine/extended profiles and incremental Windows CI; focused canonical-correct defect fixes and named concrete input/root-cause regressions for confirmed defects.
- In when #4 has actually been implemented: separate default-off scripted contour/solid property targets and measured supervised SCAD profiles, using #3 only through #4's planned adapter-backed cases. If #4 is unavailable, record the named scripted follow-up and leave the combined rollout obligation open; do not block the direct #9 family or add a queue dependency on #4.
- Out: general SCAD feasibility/ingestion, a mandatory general polygon generator, arbitrary-rotation or unrestricted numerical laws, invalid-mesh rejection at non-validating functions, repair/decimation geometry preservation, Arachne/module-kernel coverage, production API widening for tests, new IR/WIT fields, a randomized guest/pipeline campaign, and a workspace test run. A larger confirmed defect is blocking fix work for the affected direct family, not permission to weaken its oracle or mark it green.

## Design notes

### Grounded interfaces and ownership

- `Point2` is integer grid, `Point3` is f32 mm, `Polygon.points`, `ExPolygon.contour`/`holes` and `IndexedTriangleSet.vertices`/flat `indices: Vec<u32>` are defined in `crates/slicer-ir/src/slice_ir.rs`; `ExPolygon` contours are CCW and holes CW (`docs/02_ir_schemas.md`, IR 6). `Transform3d.matrix` is column-major; its derived default is zeros, while `transform_point3` deliberately treats an all-zero matrix as identity. Construct explicit affine matrices for other transforms.
- `clip_polygons`/the four wrappers use Clipper2 `FillRule::NonZero` and tree-based nesting. `clip_polylines` uses open-path intersection against a one-unit-inflated universe, permits boundary spans, skips paths shorter than two points, and documents boundary endpoints within ±2 grid units; result order across paths is unspecified. Never compare raw contour order or assume exact uninflated hole exclusion in the narrow boundary band.
- `offset` accepts f32 mm delta and explicit `OffsetJoinType`/arc tolerance; `offset2_ex` takes two f64 mm deltas, join and miter limit, returning empty if the first pass vanishes. Restrict exact formulas to the axis-aligned, clearance-separated miter families below. `smooth_outward_polygon` takes **integer grid units** for its chord, performs a near-duplicate prepass and can delete a degenerate ring. The existing deliberate far/blocked-corner divergence `DEV-141` in `docs/DEVIATION_LOG.md` remains open: do not silently undo it or assert byte-for-byte canonical equivalence for that branch.
- `slice_mesh_ex` indexes vertices directly and its `slice_make_lines` binary-searches `zs`; use only independently validated, closed, finite, nondegenerate, in-range meshes and finite **strictly increasing** planes. Invalid indices, NaNs, unsorted/duplicate planes and open meshes are not a promised rejection API. `AabbTree::new` instead drops invalid/nonfinite triangles internally; this packet tests valid-mesh query contracts and the documented empty tree, not a fabricated error. The query tree is in mesh space; transform separately.
- These public seams exist in `crates/slicer-core/src/polygon_ops.rs`, `crates/slicer-core/src/smooth_outward.rs`, `crates/slicer-core/src/triangle_mesh_slicer.rs`, `crates/slicer-core/src/aabb_tree.rs`, `crates/slicer-core/src/lib.rs` and `crates/slicer-helpers/src/split.rs`. `cross_section_at_z` (`crates/slicer-core/src/algos/mesh_cross_section.rs`) calls the actual slicer; `transform_point3` is used in `crates/slicer-core/src/algos/prepass_slice.rs`; `crates/pnp-cli/src/helpers_cmd.rs` calls `split_connected_components`. No non-test `AabbTree::new` or direct `xor` wrapper caller was found in the inspected `crates/` tree: those checks are library contracts, not claims of pipeline wiring. The underlying `clip_polygons` operation is a separate dispatch seam.
- Consume #1's planned `slicer_sdk::test_support::property_testing::{PropertyRun,CaseGuard}` and #2's exact `domains::{GeometryBounds,GeometryDomain,GeometryCase,TopologyClass,BoundaryRule,geometry_cases,line_segments,geometry_complexity,MeshCase,SolidKind,analytical_meshes,RigidTransformCase,rigid_transforms}`; use `oracles::{orientation,signed_area2,segment_relation,validate_ring,point_in_region,segment_in_region,validate_geometry,validate_indexed_mesh,mesh_signed_volume_mm3}` where their declared domains apply, and `regression::{ConcreteInput,format_regression_fixture}` for confirmed failures. #2 does **not** plan `MeshDomain`; do not invent it. `GeometryBounds` counts total vertices across rings; valid disconnected components have disjoint closures and holes are strictly contained. Its `boundary` selects query semantics, not permission for touching rings.
- Keep test-only reference models private to the new owning-crate test targets; no new shared SDK export is required. `slicer-core` and `slicer-helpers` take SDK/Proptest **dev-dependencies**, never production edges. Adding the SDK dev-edge to core must be checked against Cargo's actual dependency/feature resolution because the native SDK already depends on `slicer-core`; the helpers' prohibition on a normal `slicer-core` dependency (`docs/13_slicer_helpers_crate.md`, Dependency Rules) remains intact. Test code follows the fixture/FRU rule in `docs/21_data_defaults_and_fixtures.md`.

- Units: 1 unit = 100 nm (10⁻⁴ mm), not OrcaSlicer's 1 nm; divide OrcaSlicer constants by 100 and convert with `Point2::from_mm` / `mm_to_units()` (`docs/08_coordinate_system.md`).

For exact grid fixtures construct integer coordinates directly with unit comments. Prove checked intermediate bounds including translations, offsets, vertex-count/area products, segment intersections and grid-to-float conversions; `i128` does not imply unrestricted i64 safety. For float comparisons derive a dimensionally correct absolute error envelope from the chosen f32/f64 operation sequence, input magnitudes and grid quantization; distinguish mm, mm², mm³ and integer units. Use exact comparisons when construction proves exactness; never increase a tolerance to make a sample pass.

### Direct property charters

Each row calls its real SUT inside #1 `PropertyRun::check`, with a fresh `CaseGuard` on every generated and shrink invocation. In addition to fresh generation, run deterministic nonempty witnesses for the classes named below; do not treat random frequency or an empty loop as proof. Use #2 validators on each generated input and exposed shrink state, preserving class/minimum hole/component witnesses. Local paired-input, rectangle, mesh and query strategies must similarly preserve their own preconditions and witness during simplify/complicate; record bounded attempts and exhausted/incomplete shrinks, not a fabricated pass or global minimum. Each charter in `docs/testing/properties.md` records domain, strategy, dependencies, oracle, tolerance derivation, witness, shrink, profile/isolation, artifact/replay and concrete-regression destination.

|---|---|---|
| `H-BOOL-SET` | Bounded well-wound valid empty, convex, concave, holed and disconnected sets, plus pairs of overlapping and disjoint axis-aligned rectangles with whole-mm edges. Call all four Boolean wrappers. | On rectangles, partition at all input X/Y edges and compare every open cell with Boolean membership truth tables; whole-mm separation ensures each nonzero cell has an integer-grid interior query. Surviving rectangular passes depend on the sum of deltas and do **not** by themselves detect reversed order. | `H-OFFSET-SMOOTH` | CCW axis-aligned convex rectangles with all edge lengths above the prepass threshold, and a controlled CCW L-notch with a single 90° reflex corner, long arms and clearance greater than the positive chord. | Convex rectangle must remain geometrically unchanged. Include empty `zs`/mesh, planes outside the solid, safely interior planes, and exact bottom/top and through-vertex witnesses. Use #2 `validate_indexed_mesh(..., true)` on each nonempty generated mesh before the SUT; the deliberately empty case is separate. | Box interior cross-sections are rectangles; each controlled prism interior section is its dimension-derived XY triangle, not a call to `slice_mesh_ex` or Clipper. Compare geometric area, winding, expected component count and boundary/inside/outside membership with independently derived grid/f32 envelopes. For a cube, bottom is empty and top yields the square under the verified upper-edge ownership convention; the existing vertex-touching tetrahedron supplies a separate analytically expected triangle. Ensure every required nonempty layer actually has output. A filled/missing layer or wrong top/bottom ownership mutant fails. |
| `H-MESH-QUERY` | #2 `analytical_meshes(SolidKind::Box, ...)` and `rigid_transforms` for validated bounds/transform checks, plus locally constructed ray-friendly boxes with finite intermediates and adequate ray-hit/edge clearance. | `transform_point3` quarter-turns are independent coordinate sign/swaps plus translation, checked with a derived f32-mm bound; explicit zero-matrix and identity witnesses are separate. On axis-aligned box mesh space, `AabbTree::bounds` equals dimension-derived bounds, and normalized ±Z rays through face interiors of the ray-friendly boxes have analytically known ordered entry/exit points and distances; missed rays and an empty tree return none. A transposed transform, missing exit and fabricated hit must fail. No arbitrary rotation or ray-direction normalization promise. |
| `H-HELPERS-SPLIT` | Small indexed triangle sets with finite distinct-position vertices and valid indices: empty, disconnected solids, single triangles, vertex-only contacts, same-direction shared edges and opposite-direction shared edges. | `split_connected_components` uses **index** adjacency only for reversed directed shared edges. Build an independent bounded pairwise face-reachability model, not the production directed-edge map/DFS. Compare the output partition as oriented face multisets after resolving component-local vertex indices; assert every input face appears exactly once, singleton fragments survive, components are seeded in ascending first-face order, and vertex-only/same-direction contacts do not join. Closed analytical inputs also satisfy #2's independent mesh predicate. A vertex-adjacency mutant, a same-direction-edge mutant and dropped singleton fail. |

The Boolean sample oracle does not prove equality at unobserved points for general polygons; exact rectangle cells and area are the complete restricted model, while broader topology observations are explicitly bounded. Quantization, f32 epsilon near slicing planes, near-collinearity, offset rounding and output boundary contacts each require their own checked precondition or error envelope. Do not use `validate_geometry` with the input topology class as a blanket output validator: correct Boolean/offset operations can change class. `mesh_signed_volume_mm3` is a tetrahedral-sum oracle for independently dimensioned test solids, not proof of arbitrary 3D self-intersection freedom.

## Acceptance criteria

`C`, `H`, `P`, `S` and the required log wrapper are defined in Verification. All new named tests below are planned. A no-test/ignored/missing-property run is failure, not acceptance.

- **AC-1** `H-BOOL-SET` under `P` invokes `union`, `intersection`, `difference` and `xor`; exact rectangle cells/area and nonempty independent general membership observations agree for overlapping, disjoint, empty, holed and disconnected cases. `geometry_controls_boolean_and_clip_mutations` under `C` rejects both wrong-operand and filled-hole results.
- **AC-2** `H-BOOL-CLIP` under `P` checks every retained interval/segment and expected nonempty interval in the specified controlled clipping scenes, including the one-unit inflation and ±2-unit endpoint policy; short and fully outside paths produce no output. The same control rejects hole/concavity shortcuts and omitted spans, including endpoints-and-midpoint-inside counterexamples.
- **AC-3** `H-OFFSET-MITER` under `P` checks positive/negative/unequal two-pass rectangle and annulus bounds/area with verified clearance, correct hole direction and first-pass collapse. `H-OFFSET-SMOOTH` checks the convex and controlled L-chamfer contracts, and the explicit tiny CW deletion witness. `geometry_controls_offset_and_smooth_mutations` under `C` rejects reversed sign/order, lost hole and incorrect chord setback without imposing a general round trip or superset.
- **AC-4** `H-MESH-SLICE` under `P` compares actual boxes/prisms at outside, interior, exact bottom/top and through-vertex planes to the independent reference, with a positive-output assertion for each nonempty expected layer. `geometry_controls_vertex_plane_and_hole_witnesses` and `geometry_controls_slice_and_query_mutations` under `C` detect a wrong boundary-ownership result and an omitted/filled cross-section.
- **AC-5** `H-MESH-QUERY` under `P` checks dimension-derived box bounds, explicit zero/identity and quarter-turn/translation transforms, normalized entry/exit rays, misses and empty-tree behavior. Its control rejects a transposed transform, missing exit and false hit. Error envelopes and nondegenerate ray clearance are derived and recorded.
- **AC-6** `H-HELPERS-SPLIT` under `P` compares every oriented face and the connected partition to the independent pairwise reachability model; vertex-only and same-direction contacts remain separate, opposite-edge neighbors join, singleton fragments survive, and component first-face order is preserved. `helper_controls_edge_adjacency_and_singleton_mutations` under `H` rejects each corresponding wrong result.
- **AC-7** For every direct ID, measured Windows routine and extended profiles actually execute the exact registered property and accepted-case evidence; `docs/testing/proptest-geometry-evidence.md` records separate compilation/execution/generation/shrink measurements, numerical bounds, witnesses and source/feature/seed provenance. The #1 `properties-windows` required PR job runs the incremental registry and its logs show the new direct IDs; artifacts are uploaded on failure. The direct suite and relevant existing narrow tests pass without weakened assertions or new skips.
- **AC-8** If #4 is implemented by #9 closure, both exact scripted IDs execute under `S` in measured routine and extended Windows runs, through #4's whole-process supervision; independent Boolean/mesh references detect removed holes/bodies and all-outside answers, and the SCAD Windows lane records execution and failure artifacts. If #4 is not implemented, the direct evidence instead explicitly records both IDs as pending, the #4/#3 gating and a later #17 audit; no scripted execution or combined gate is claimed.
- **AC-N1** Controls under `C`/`H` reject the named bad results and nonempty-population checks prevent vacuous success. `geometry_controls_owned_shrink_witnesses` and `helper_controls_owned_shrink_witnesses` prove nonminimal examples shrink as specified while every exposed value retains its named witness. Invalid or overflowing profile bounds fail before sampling; exhaustion, missing selected property, lost shrink witness, latent generator/adapter errors and uncompleted shrinking are never reported as a passed property.
- **AC-N2** Every confirmed new production defect has a focused canonical-correct fix and named, concrete, RNG/engine-independent regression containing the root cause and formerly failing input; its property and affected existing tests pass. If none is found, evidence says so and no artificial production regression is claimed. Larger unresolved defects block the affected direct family rather than being waived.

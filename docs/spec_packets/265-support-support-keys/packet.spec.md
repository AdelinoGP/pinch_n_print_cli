# Packet Contract: support-support-keys

## Goal

Cover all 12 P13 Support / Support keys (`enforce_support_layers`, `raft_first_layer_expansion`, `support_bottom_z_distance`, `support_critical_regions_only`, `support_expansion`, `support_object_first_layer_gap`, `support_object_xy_distance`, `support_remove_small_overhang`, `support_style`, `support_threshold_angle`, `support_threshold_overlap`, `support_type`): wire the one genuinely missing input (`enforce_support_layers` — a host decision point exists at `SupportContactParams::enforce_support_layers` but `resolve_contact_params` hardcodes `0`), declare the family-agnostic support-analysis keys in both planner manifests with canonical types/defaults/bounds, re-adjudicate the five decision-point-less keys as declared-with-gap (non-perturbing), and pin every disposition with manifest guards, invariant tests, bounds arms, and CONFIG_BLOCK honesty.

## Scope Boundaries

The packet touches the two planner manifests (`tree-support-planner.toml` — 9 net-new tables; `traditional-support-planner.toml` — 8 net-new tables), a type correction on `traditional-support.toml` (`support_style` string → canonical 7-value enum), the host wiring in `crates/slicer-runtime/src/builtins/support_analysis_producer.rs::resolve_contact_params` (one field: `enforce_support_layers`), three net-new module guard test files, one net-new non-perturbation test file, arms in two existing integration binaries, the producer's own tests mod, and the generated `docs/15_config_keys_reference.md`. It does not implement any of the five declared-with-gap decision points (bottom Z gap, first-layer XY override, critical-regions machinery, small-overhang cluster filter, raft first-layer geometry), does not touch the already-wired `support_object_xy_distance` / `support_threshold_angle` declarations or the host-key defaults in `docs/config/host-keys.toml` (all canonical-faithful — verified at authoring), and adds no `ORCA_CONFIG_PADDING` / `SUPPORT_CONFIG_DEFAULTS` twins.

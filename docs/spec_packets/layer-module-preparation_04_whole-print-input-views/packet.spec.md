# Packet Contract: whole-print-input-views

## Goal

Expose bounded, declaration-gated typed committed whole-print inputs to native and WASM preparation, with separate owner-selected source/configuration projections from the shared ordinary targeting seam.

## Scope Boundaries

Approved eight-queue row 04 owns input transport, not preparation scheduling or algorithm correctness. Read context includes unselected regions; selected targets describe eligible source contexts, never predicted Layer output. Authoring changes only these five contracts: draft, no implementation, activation, execution gates or commit.

## Architecture Constraints

- Host-emitter ownership stands (ticket-27 hazard checked): canonical's reads are all `GCode::_extrude` emission-time feedrate adjustments, not placeholder publication — `machine-gcode-emit`'s generic `[key]` sweep is the wrong seam. No manifest declaration (host-only keys; P35 `enable_pressure_advance` precedent omits `to_config_map`).
- ADR-0052 conformance: per-point factor REPLACES the whole-entity scalar (fallback, never composition). The resonance adjustment applies to the factored speed after the existing `clamp(0.05, 5.0)` + `* 60.0` shaping, per point. No ADR amendment.
- Ticket-113 conformance: canonical min-0 is a GUI hint (`PrintConfig.cpp` spinner only; `Config.cpp` never enforces). Enforcing it here is a deliberate divergence recorded in DEV-174(a), not parity.
- No `ORCA_CONFIG_PADDING` edit (Authoring rule 2). The table is load-bearing for the ≥80-pair floor but resonance keys thread via the resolved config; AC-N3 pins honest absence.
- Scalar-global is parity, not divergence: canonical declares all three scalar (`coBool` / `coFloat` / `coFloat`), so no vector DEV and no ticket-125 engagement.

  - Widening to per-filament vectors now: rejected — canonical is scalar; ticket-125 owns no model here.

Canonical block ported (verbatim grounding, `GCode::_extrude` in `GCode.cpp`):

```cpp
if (path.role() == erExternalPerimeter && m_config.resonance_avoidance.value) {
    if (ref_speed > m_config.max_resonance_avoidance_speed.value) {
        m_resonance_avoidance = false;
    }
    if (FILAMENT_CONFIG(filament_max_volumetric_speed) > 0) {
        speed = std::min(speed, FILAMENT_CONFIG(filament_max_volumetric_speed) / _mm3_per_mm);
    }
    if (m_resonance_avoidance && speed < m_config.max_resonance_avoidance_speed.value) {
        if (speed < m_config.min_resonance_avoidance_speed.value +
                ((m_config.max_resonance_avoidance_speed.value - m_config.min_resonance_avoidance_speed.value) / 2)) {
            speed = std::min(speed, m_config.min_resonance_avoidance_speed.value);
        } else {
            speed = m_config.max_resonance_avoidance_speed.value;
        }
    }
    m_resonance_avoidance = true;
}
```

Port mapping: `erExternalPerimeter` → `ExtrusionRole::OuterWall` (only that variant; `Custom`/`GapFill`/`RaftInfill` fallbacks are PnP inventions with no canonical standing and stay unadjusted); `ref_speed`/`speed` collapse to the single factored speed (DEV-174(c)); the `m_resonance_avoidance` flag becomes a pure per-point predicate (speed > max → bypass), which is observably identical without carried state; the loop reset needs no port.

DEV-174 (single row, three clauses): (a) min-0 enforcement — canonical declares GUI min 0 and never enforces (`Config.cpp` ignores min/max); the port rejects negatives and inverted ranges at the emitter (ticket-113 class). (b) volumetric re-cap omitted — Tier D, no emitter-path source. (c) ref/speed collapse — identical absent the cap.

## Locked Assumptions and Invariants

- Defaults locked to canonical (`false` / `70.0` / `120.0`); midpoint `95.0` derived, not configured.
- Adjustment fires only for `ExtrusionRole::OuterWall` with avoidance on and factored speed below max; everything else is identity.

- Change is reversible via defaults: avoidance off restores HEAD feedrates exactly.

## Risks and Tradeoffs

- Midpoint-boundary float equality (`speed == 95.0` goes upper): matches canonical `<` shape (strictly-below-midpoint takes the min arm); pin with an exact-boundary test to prevent `<` vs `<=` drift.
- `f32` vs canonical `float`: same width; rounding already happens in `resolve_feedrate` (`* 1000 round / 1000`); adjustment applies pre-rounding like the base speed.
- DEV-172/173 collision lesson: drafts 276/277/281 proposed DEV-171/172/173 while LOG already held DEV-171 (ticket 47 landed first); this packet takes DEV-174 as first collision-free — implementer must re-derive `max(DEV-*)` over LOG + `docs/spec_packets/*/`, not LOG alone, before writing the row.

# Packet Contract: config-schema-registry

## Goal

Relocate the shared schema and region-split carriers, create `slicer-config` over `slicer-ir`, and assemble a deterministic four-channel `ConfigSchemaRegistry` with structurally validated selector metadata, validated base-key metadata, reconciled declarations, repaired manifest types, and an independent census oracle.

## Scope Boundaries

This packet owns the row-1 topology and relocation work, ADR-0019 closure, the four declaration-channel registry, selector metadata propagation plus structural selector validation, base-key/denied-scope validation, the owner-authorized `validate` retirement and minor wire bump, the three manifest type repairs with reader migration, and the generated-schema documentation gate. It also authors the `wall_generator` host selector's explicit per-region denials and updates the bounded `RegionMapping (Builtin) — aggregated_region_split Threading` section in `docs/04_host_scheduler.md` to record the completed type relocation and removed core→scheduler edge. It does not implement typed scoped ingestion, automatic-value expansion, scope resolution, registry-driven delivery, the broad machine/emitter deny-list rollout, layer-range geometry, or any queue row after row 1; packet 7 (`TASK-568`) owns that broad deny-list rollout.

The host runtime carrier is deliberately const-safe: `HostRuntimeKey` contains seven static fields (`key`, `field_type`, `scope`, `default`, `meta`, `selector`, `denied_scopes`), with `denied_scopes: &'static [&'static str]`, not a `HostConfigKey` field. Its `wall_generator` row explicitly denies `object`, `layer_range`, `modifier`, `paint_semantic`, and `tool`, in that order; `global`/`print` remains allowed. Registry/channel assembly converts each runtime row to `HostConfigKey` when a common host entry is needed and copies the static denials into `RegistryEntry`; this relocation does not add `selector` or `denied_scopes` to the existing config-schema JSON wire object.

## Prerequisites and Blockers

- Depends on: none; this is approved plan queue row 1.
- Unblocks: queue rows 2–10, which consume the registry exports and relocated IR types.
- Status and ownership: remain `active` and `TASK-562`; the packet does not edit `docs/07_implementation_status.md` or the approved plan.
- Activation blockers: preflight must pass, every step exit must be falsifiable, and no implementation step may widen the listed edit surface.

## Compatibility Checklist

- IR schema versions: none; no `CURRENT_*_SCHEMA_VERSION` changes.
- WIT packages: none; no `crates/slicer-schema/wit/**` edit and no guest interface change.
- CLI wire: `CONFIG_SCHEMA_WIRE_VERSION` changes from the live `"1.2.0"` to `"1.3.0"` under owner decision 1, even though the default policy classifies removal as major.
- Manifest schema: `selector`, `base_key`, and `denied_scopes` become optional per-field declarations; `validate` and the documented `[[config.cross-validate]]` surface are retired. New fields use serde defaults so existing declarations remain readable.
- Guest artifacts: the five guest source readers are in the build path; `cargo xtask build-guests --check` must return exit 0 after their migration.
- ADRs: only ADR-0019 is amended, changing its status to Closed and recording the relocation closure; no new ADR is authored.

## Architecture Constraints

- ADR-0066 owns optional committed XY diagnostics alongside immutable opaque pieces. No module drawing export, provider argument, new stage, ordinary IR accessor or lightning special case.
- Additive companions avoid widening existing public request/capture/manifest/IR structs. Add a CapturedIr enum variant and update its true exhaustive arms in the same step; StageCapture layout remains unchanged. Existing hard-version assertions and constructor literals remain untouched.

### Validation and accounting

One scene per requested declared view per owner; scene identity is `(print, owner, view, scene_id)`. Nonempty scene id/view/class/primitive ids use exact UTF-8 matching. Unique class ids within scene and primitive ids within scene; duplicate view publication is DuplicateScene regardless of scene id. Empty/duplicate scene/class/primitive ids or unknown class/layer references are InvalidReference (duplicate publication stays DuplicateScene). All primitive class references must be listed. `global_layer_index` must exist in the committed schedule; host attaches finite nonnegative schedule Z, never accepts module Z. A whole-print scene may include context layers where the owner is not selected; read context does not grant private output ownership to another module. Access errors never poison or mutate a foreign owner's transaction; caught invalid writes poison only the invocation whose output sink is being used.

Polyline has at least two distinct consecutive vertices and is open (first != last). Polygon contour/holes have at least three distinct vertices, no repeated terminal vertex, nonzero signed area, simple rings, CCW contour/CW holes, strict contained nonintersecting holes; reject touching/intersecting/self-crossing/degenerate rings, do not repair or normalize them. Use checked integer predicates (i128 conversions/subtractions/products/sums); predicate overflow is InvalidCoordinate, retention/count overflow ArithmeticOverflow. Float-boundary conversions/bounds/Projector inputs must be finite; capture integer identities unchanged. No arbitrary maximum-size coordinate or plan quota is introduced. Empty primitive vector with explicit scene/classes is valid; omitted scene is MissingScene.

Diagnostic logical bytes are checked sums of UTF-8 scene/view/class/id/label bytes plus 8 bytes per Point2 coordinate pair component (16 per point), 4 per global_layer_index and 1 per geometry tag/filled flag where applicable. Count each actual stored string occurrence and geometry item exactly once; do not count Vec/Arc/allocator overhead. Expose sidecar `PreparationDiagnosticAccounting { staged_bytes: u64, retained_bytes: u64, published_scenes: u64 }` from store metadata via an additive method, not new PreparedPlanMetadata fields. Put/read/name/payload counters remain #03's own totals; #05 transferred_bytes still means actual prepared-piece returned_read_bytes only. Capture records diagnostic retention before disposal separately and shares typed snapshot Arcs after private storage cleanup.

The default metadata-only function is unchanged. The visual function forwards through #05's shared startup/pipeline core with private requested-tap completion mode; it validates frozen declarations before preparation, resolves requested layers and eligible owner participation after committed prepass, runs preparation once and captures post-Ready typed snapshots. With stage taps, use the same lifecycle-aware PreparedLayerStageRunner through the real truncated selected-layer capture executor; postpass taps retain existing whole-print closure. Do not run an independent preparation-only slice then a second slice to compare output. Snapshot metadata before disposal and drain active calls before cleanup.

Add `CapturedIr::PreparationProjection(Arc<CommittedPreparationProjection>)`; schema_version_string returns pinned `"1.0.0"` for that variant without adding an IR schema constant. Each StageCapture has the real owning consumer stage, selected global layer/Z and the same whole-print scene Arc. Capture phase/view/owner are obtained from the companion and committed scene, never inferred from ordinary stage id or payload name. Rendering refuses ordinary overlays/tool-color/extrusion styles on this variant; points are circles, open paths screen-space strokes, outline rings outlines, filled polygons retain holes. Paint order is filled polygons, outline polygons, polylines, points, then labels; within each kind use sorted class/id so fills cannot erase point glyphs. Deterministic sorted `(module_id, view, class)` palette/glyph assignment uses the entire scene, not selected-layer appearance. Projector is the sole world-to-pixel transform. Model frame unions full model and full requested scenes with existing margin; plate frame remains exactly bed bounds. Ordinary mixed captures use that same bound. The class_legend lists exact class, RGB, point glyph and screen stroke; these are presentation values, not physical deposition dimensions.

Verified current layout: `CapturedIr` derives `Debug, Clone, PartialEq, serde::Serialize` and uses `#[serde(tag = "kind", content = "value")]`; `StageCapture` derives Debug/Clone/PartialEq but not Serialize. Preserve these derives/layouts. Annotate only the new variant's tuple field with `#[serde(serialize_with = "serialize_preparation_projection")]`. Add private `serialize_preparation_projection<S>(projection: &Arc<CommittedPreparationProjection>, serializer: S) -> Result<S::Ok, S::Error> where S: serde::Serializer` in `crates/slicer-runtime/src/layer_executor.rs`; its entire serialization operation is `serde::Serialize::serialize(projection.scene(), serializer)`. No Serialize implementation/derive is added to CommittedPreparationProjection, store, handles, accounting or opaque plan types; neither Arc's serde support nor serialization of the private committed object is required. The enum keeps its tagged envelope: `{ "kind": "PreparationProjection", "value": { "scene_id", "view", "classes", "primitives" } }`, where value is only the validated public SDK scene DTO.

Step10 owns `preparation_projection_serializes_only_scene` in the existing auto-discovered `crates/slicer-runtime/tests/visual_debug_render_tap_tdd.rs` binary, alongside its existing exhaustive-match update. Its same-file helper invokes the production native fixture/binding to obtain a Ready committed snapshot (using the Step9a runtime fixture dependency); it cannot construct a private committed-store type or inject a ready plan. For a one-layer fixture, compare the complete nonempty serialized enum against independently authored literal JSON containing the four known primitive ids, classes, labels, exact coordinates and Point/Polyline/Polygon tags; assert exact value keys `scene_id`, `view`, `classes`, `primitives`. Exact JSON equality rejects any added owner/store/accounting/piece/codec/payload/handle field, without a narrow blacklist. The serialized public scene remains usable after private-store disposal. CLI per-image `typed_capture` preserves this kind/value envelope and projects only `value.primitives` to the rendered layer, without cloning retained whole-print snapshots or deriving any value from opaque bytes; retain full scene classes for subset-stable legends.

CLI adds pinned `VERSION_1_4 = "1.4.0"`, not a live replacement for legacy constants. Preserve Name/Detail legacy accepted forms. New visualization kind `preparation_geometry` applies only to preparation taps, existing kinds only to stage taps; partition rather than apply the Cartesian product. Its options permit omitted/`view: "xy"` only; front/side, tool coloring, overlays and unknown keys fail closed. Preparation taps without preparation_geometry are rejected, not silently dropped.

New CLI errors are the exact names in AC-N2: syntax/schema/source/dimension variants belong to `ValidationError`; owner/view/unsupported/inactive/typed projection variants belong to `VisualDebugError`. They carry the named module_id/view/dimension or schema detail; `PreparationProjectionRejected { module_id: String, view: String, reason: PreparationProjectionError }` includes the projection enum name and identity. Map the separate runtime typed error by enum match, never SliceRunError string parsing. Owner/view syntax/declaration/source/dimension validation precedes module invocation; inactive/layer resolution uses real shared selection and schedule before any prepare. Unknown/undeclared view is not an empty scene.

NET-NEW private CLI `PreparationManifest`/`PreparationImageEntry` companions in `crates/pnp-cli/src/visual_debug_preparation.rs` serialize a common legacy manifest plus typed preparation entries; do not add fields to Manifest/ImageEntry. Declared/inactive owners do not appear as executed.

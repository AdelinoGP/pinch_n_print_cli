# Implementation Plan: pbt-walls

Implement only after `proptest-openrscad_02_pbt-domains` and its foundation prerequisite are implemented and their actual exports, feature names, registry schema and runner context have been rechecked on disk. All new test names, features and registry records below are planned additions; no authoring-time test or measurement result is implied. The spec defines `M`, `F`, `P`, the `run_logged` Bash wrapper, Windows exit-status handling and the rule to read/archive `target/test-output.log` before overwriting it. Write the independent oracle and its mutation control before asserting the property: a control that accepts the mutation means the oracle is not ready. Each step leaves the default and feature-enabled trees compiling, and no step adds a live registry record before its test exists and its profile is measured.

## Step 3: Implement the classic structure oracle and property

- Objective: prove role-appropriate closure, band/role metadata and parallel-array alignment for real `emit_walls` output without asserting a universal wall count.
- Surface: `modules/core-modules/classic-perimeters/src/property_tests.rs`:
  - private `ClassTag`/`EmitMode`/`ClassicCase`/`ClassicOutput` fixtures and a checked `bounds`/domain builder;
  - `classic_structure_oracle`, `proptest_classic_wall_structure`, `classic_required_witnesses_are_nonempty`, `classic_structure_oracle_rejects_mutations`, `classic_shrink_preserves_emit_mode_and_topology`;
  - `ClassicPerimeters::from_config` setup with the five declared keys; direct private `emit_walls` calls with a fresh `PerimeterOutputBuilder` per invocation.
- Approach: prebuild and validate the four #2 class strategies, then select the topology class with `prop::sample::select(vec![Convex, Concave, Holed, Disconnected]).no_shrink()` and `prop_ind_flat_map` into the matching prebuilt `geometry_cases` strategy; never `prop_oneof!` over class strategies, because the outer union could switch topology during shrinking. The closure cannot fail or fall back during generation. Certify every generated case with `validate_geometry` before invoking the SUT. Use the registry bounds for `GeometryBounds` and wall/width/height limits with checked conversion. Build valid widths above the `line_width_to_spacing` threshold. Select the emit mode and `variant_fuzzy` with `prop::sample::select(vec![...]).no_shrink()`, never a `prop_oneof!` of `Just` mode arms; keep the ordinary scalars shrinkable. Call `emit_walls` with `detect_thin_wall = false`, `medial_axis_enabled = false`, `precise_outer_wall = false`, `WallSequence::InnerOuter`, empty segment annotations and `PathAnnotationMode::Unconsumed`, so the domain emits ordinary `Outer`/`Inner` loops only. Implement the exact oracle checks in the spec: band range, role/loop/speed mapping, closure/`points.len() >= 4`/distinct consecutive XY, parallel lengths, exact z/width/flow/default annotations, `fuzzy_skin == variant_fuzzy`, mirrored closing width/flag and `None` tool/order-lock. Use bitwise float comparison for copied values. Keep a local in-process nonempty counter and a deterministic 20 mm/3-band witness in both `variant_fuzzy` modes. The mutation control must clone a real witness output and change one field at a time; every mutation must be rejected. Implement `classic_shrink_preserves_emit_mode_and_topology` as a deterministic protocol probe for each of the four class tags: `TestRunner::deterministic()`, `Strategy::new_tree`, then `complicate`/`simplify` calls that must leave the selected class, emit/variant modes, the fixed topology and the band/role invariants unchanged, keep each current geometry `validate_geometry`-valid, and change at least one ordinary scalar; also assert the no-shrink class/mode trees' `simplify` and `complicate` return `false`. A false-only sequence is a probe failure.
- Fallout: no production fields. Every `Point3WithWidth`/`WallFeatureFlags`/`WallLoop`/`ExtrusionPath3D` literal in the new file must use the fixture base/FRU or a reasoned `// exhaustive:` waiver; add the site to the manual review. `ClassicCase` is private and not watched.
- Verify: `M`'s `classic_required_witnesses_are_nonempty`, `classic_structure_oracle_rejects_mutations` and `classic_shrink_preserves_emit_mode_and_topology`; specifically `run_logged cargo test -p classic-perimeters --features property_testing --lib -- property_tests::classic_shrink_preserves_emit_mode_and_topology --exact --nocapture`; `cargo check -p classic-perimeters --all-targets --features property_testing`; after the test callback exists, pilot the property through the foundation's controlled context, not a live registry record. Do not register `M-CLASSIC-WALL-STRUCTURE` until Step 7 measures its profile.
- Done when: the real private kernel is exercised; the deterministic witness is nonempty with bands `{0,1,2}`; the generated nonempty counter is positive during the pilot; every mutation is rejected; the shrink probe preserves the no-shrink modes/topology and observes an ordinary value change; the oracle does not compare wall/band count to `wall_count`.

## Step 4: Implement classic band selection, capacity and degenerate controls

- Objective: prove the emit gates, allowed-prefix band invariant, capacity behavior and the documented degenerate/fatal paths without turning a capacity difference into a failure.
- Surface: `modules/core-modules/classic-perimeters/src/property_tests.rs`: `classic_band_oracle`, `proptest_classic_band_selection`, `classic_band_oracle_and_degenerate_cases`, `classic_negative_spacing_is_fatal`, `classic_property_domains_reject_unsafe_bounds`, plus the deterministic 1 mm/10-band, 2-point, collinear and empty witnesses.
- Approach: reuse the Step 3 geometry/scalar families and select the three emit modes with one `prop::sample::select(vec![Both, OuterOnly, InnerOnly]).no_shrink()` strategy, never a union of `Just` arms. Implement the allowed-prefix rule over collected band indices, the `wall_count` upper bound, the `emit_outer == false` no-outer/no-seam check, the `emit_inner == false` no-inner/no-infill check and the `wall_count == 1` single-band case. Never compare the emitted band or wall count to `wall_count`. Call the SUT on the deterministic 2-point/collinear/empty inputs and assert no walls, no infill areas and no seam candidates. Call it with a width below `layer_height * (1 - PI/4)` and assert `ModuleError.code == ERR_NEGATIVE_SPACING` and `fatal == true`; ensure the valid property domain never enters this path. The mutation control adds a band gap or a gate-violating role and requires the band oracle to reject it. Implement `classic_property_domains_reject_unsafe_bounds` against the local checked bound/domain builder and assert exact `DomainError` variants: `ArithmeticOverflow` for `max_abs_units > i64::MAX` / `max_wall_count > u32::MAX`, and `InvalidBounds(_)` for a missing key, zero/too-small wall count, impossible hole/component/vertex minima, nonpositive width/height, and a width/height pair whose `line_width_to_spacing` margin is nonpositive. No owner-local test may silently default a bound.
- Fallout: same manual literal review; no new watched-type shape. The capacity witness's actual count is established by execution, not assumed.
- Verify: `M`'s `classic_band_oracle_and_degenerate_cases`, `classic_negative_spacing_is_fatal` and `classic_property_domains_reject_unsafe_bounds`; specifically `run_logged cargo test -p classic-perimeters --features property_testing --lib -- property_tests::classic_property_domains_reject_unsafe_bounds --exact --nocapture`; `cargo check -p classic-perimeters --all-targets --features property_testing`; pilot `M-CLASSIC-BAND-SELECTION` through the controlled context. Do not register it before Step 7.
- Done when: the capacity witness emits at least one and fewer than 10 bands and still satisfies the allowed-prefix oracle (or the smallest documented nonempty capacity witness and its actual count are recorded); degenerate inputs emit nothing; the fatal spacing path is observed; the bound/domain rejections assert the exact `DomainError` variants; every band/gate mutation is rejected.

## Step 5: Implement fuzzy repeatability and span preservation

- Objective: prove deterministic output for identical arguments and exact preservation of unselected spans and original endpoint metadata, without claiming universal metadata preservation.
- Surface: `modules/core-modules/fuzzy-skin/src/property_tests.rs`:
  - private `FuzzyCase`/`FuzzyOutput`/`InsertedSample` fixtures and checked bounds/domain builders;
  - bitwise point/flag/width comparator, `match_fuzzy_output`, `fuzzy_repeatability_oracle`, `proptest_fuzzy_repeatability`, `proptest_fuzzy_span_preservation`;
  - `fuzzy_required_witnesses_are_nonempty`, `fuzzy_repeatability_control`, `fuzzy_span_oracle_rejects_mutations`, `fuzzy_disabled_parameters_are_identity`, `fuzzy_property_domains_reject_unsafe_bounds`, `fuzzy_shrink_preserves_modes_and_fixed_prefix`.
- Approach: build bounded canonical-unit point vectors, per-point `WallFeatureFlags`, parallel positive widths, `apply_to_all`, positive thickness/point_distance and arbitrary layer/wall indices. Select `apply_to_all` and open/closed topology with `prop::sample::select(vec![...]).no_shrink()`, never a `prop_oneof!` of `Just` mode arms; construct every generated case with a fixed `Just` leading nonzero segment whose start flag is fuzzy, then append generated points; when `apply_to_all=false`, also append a fixed `Just` following segment whose start flag is false. These `Just` prefixes are outside any union, so they cannot switch arms; the no-shrink selectors keep the modes fixed. This keeps the required selected/unselected witness and guarantees at least one inserted sample for the displacement property; when `apply_to_all=true`, every segment is selected by definition. Allow zero-length consecutive points in the generated tail as a documented degenerate mode; do not filter them out. Build the input `ExtrusionPath3D` with `extrusion_path3d_base(ExtrusionRole::OuterWall)` plus FRU. Call the real private `apply_fuzzy_skin` directly. Implement the ordered span matcher: first point exact, each segment either no insertion and exact endpoint (unselected or zero-length) or at least one inserted sample followed by the exact endpoint (selected nonzero). Compare unselected original points, flags and widths by bits. Inserted flags and profile widths must equal one of the corresponding segment endpoint values exactly; do not assert inserted `Point3WithWidth.width`. The deterministic closed square uses flags `[true, false, true, true, true]`, widths `[0.4, 0.5, 0.4, 0.45, 0.4]`, thickness 0.3 mm and point_distance 0.8 mm; segment 1 must be untouched and segment 3 (the closing edge) must have samples. Also run the same square with `apply_to_all=true` (all segments selected) and with all flags false plus `apply_to_all=false` (exact copy). The repeatability control compares two calls by bits, proves a one-bit mutation is rejected, and shows a changed `layer_index` changes the multi-sample witness. The disabled-parameter control checks nonpositive/nonfinite thickness/point_distance and a `<2`-point path return exact copies. Implement `fuzzy_property_domains_reject_unsafe_bounds` against the local checked bound/domain builder and assert exact `DomainError` variants: `ArithmeticOverflow` for `max_abs_mm_units > i64::MAX`, and `InvalidBounds(_)` for a missing key, `max_points < 3`, zero/too-small thickness or point_distance, and an unsafe count/length conversion. Implement `fuzzy_shrink_preserves_modes_and_fixed_prefix` as a deterministic protocol probe: `TestRunner::deterministic()`, `Strategy::new_tree`, then `complicate`/`simplify` calls that must leave `apply_to_all`, open/closed topology, the fixed prefix points/flags and the output closure invariant unchanged while at least one ordinary tail point/width/length changes; also assert the no-shrink mode tree's `simplify` and `complicate` return `false`. A false-only sequence is a probe failure. SUT-output violations are `TestCaseError::fail`, never `Reject` or `prop_filter`; no input-validity filter may hide a SUT-output failure. Mark the determinism-pin control with a `// test-quality:` waiver naming the determinism exception.
- Fallout: the fuzzy file contains `Point3WithWidth`, `WallFeatureFlags` and `ExtrusionPath3D` literals; every site must use FRU/base or a reasoned waiver and be added to the manual review. No production fields.
- Verify: `F`'s `fuzzy_required_witnesses_are_nonempty`, `fuzzy_repeatability_control`, `fuzzy_span_oracle_rejects_mutations`, `fuzzy_disabled_parameters_are_identity`, `fuzzy_property_domains_reject_unsafe_bounds` and `fuzzy_shrink_preserves_modes_and_fixed_prefix`; specifically `run_logged cargo test -p fuzzy-skin --features property_testing --lib -- property_tests::fuzzy_property_domains_reject_unsafe_bounds --exact --nocapture` and `run_logged cargo test -p fuzzy-skin --features property_testing --lib -- property_tests::fuzzy_shrink_preserves_modes_and_fixed_prefix --exact --nocapture`; `cargo check -p fuzzy-skin --all-targets --features property_testing`; pilot both properties through the controlled context. Do not register them before Step 7.
- Done when: the mixed closed witness inserts only on segments 0, 2 and 3; the same square with `apply_to_all = true` inserts on every nonzero segment; the same square with all flags false and `apply_to_all = false` is an exact copy; unselected segment 1 is bit-identical; repeatability is exact; the mutation controls reject the named changes; disabled inputs are exact copies; the bound/domain rejections assert the exact `DomainError` variants; the shrink probe preserves the no-shrink modes/fixed prefix/closed-loop invariant and observes an ordinary tail change.

## Step 6: Implement fuzzy displacement measurement and property

- Objective: independently measure inserted-sample displacement and longitudinal position against the corresponding source segment with a derived tolerance, without reproducing the SUT's RNG.
- Surface: `modules/core-modules/fuzzy-skin/src/property_tests.rs`: `fuzzy_displacement_tolerance`, `fuzzy_measure_displacement`, `check_inserted_displacement`, `proptest_fuzzy_displacement`, and `fuzzy_displacement_oracle_rejects_mutations`.
- Approach: reuse `match_fuzzy_output` to attribute every inserted sample to its source segment by output order. The fixed `Just` leading selected segment (outside any union) guarantees at least one measured sample; `apply_to_all` and open/closed topology are no-shrink selectors, so they cannot flip during `simplify`/`complicate`. The generated tail still explores variety. Compute in f64 the perpendicular distance to the infinite source line and the projection parameter on the segment. Assert finite, nonnegative distance at most `thickness + fuzzy_displacement_tolerance(max_abs_mm, thickness)` and longitudinal projection within `[-tol_t, 1 + tol_t]`, where `tol_t = tolerance / seg_len + 8 * f64::EPSILON`. Implement the tolerance as `K * f32::EPSILON * (max_abs_mm + thickness_mm + 1.0)` and record the derivation of `K` from the actual f32 operation sequence and the f64 measurement in the evidence; do not tune it to observed output. The deterministic closed square must contain at least one closing-edge sample with positive measured displacement. The mutation control must reject a sample displaced above `thickness + tolerance`, a sample moved beyond the segment's longitudinal span and a sample attributed to an orthogonal wrong segment. Do not assert containment in the source region or equality of the RNG displacement. SUT-output failures are `TestCaseError::fail`, never `Reject`/`prop_filter`.
- Fallout: the tolerance helper is private test code; no production change. Add its derivation and control names to the evidence.
- Verify: `F`'s `fuzzy_displacement_oracle_rejects_mutations`; `cargo check -p fuzzy-skin --all-targets --features property_testing`; pilot `M-FUZZY-DISPLACEMENT` through the controlled context. The Step 5 `fuzzy_shrink_preserves_modes_and_fixed_prefix` must also show the displacement case's fixed leading segment and modes survive. Do not register it before Step 7.
- Done when: the property measures every inserted sample through the independent matcher; the witness has a positive closing-edge displacement; all three mutation classes are rejected; the shrink probe preserves the leading segment and no-shrink modes; the tolerance derivation is recorded and no observed-output epsilon is used.

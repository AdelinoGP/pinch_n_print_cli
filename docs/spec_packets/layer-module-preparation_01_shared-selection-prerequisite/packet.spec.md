## Public Forward-Dependency Interface Summary

Runtime's public `build_and_commit_layer_selection_index` (`crates/slicer-runtime/src/layer_executor.rs`) is the single production late-bind build/commit entry, used by both pipeline paths, `prepare_prepass_context` (`crates/slicer-runtime/src/run.rs`), and runtime test fixtures driving executor entry points directly; it is public so fixtures provision through the same path.

The following public Rust contracts already exist in `crates/slicer-wasm-host/src/selection.rs`, exposed by `pub mod selection` in `crates/slicer-wasm-host/src/lib.rs`. Repair them in place; do not pretend the existing seam still needs initial creation. Source identity, not a temporary map-space config address, is the repaired storage/output convention:

- `pub fn build_layer_selection_index(input: LayerSelectionIndexInput<'_>) -> Result<LayerSelectionIndex, LayerSelectionBuildError>` builds the whole-print index ONCE, after late PrePass and global-layer promotion, before any Layer invocation. A private per-layer routine may be reused internally; there is no public per-call reconstruction API.
- `pub struct LayerSelectionBuildError { pub error: SelectionError, pub stage_id: String, pub module_id: String }` carries the failing input module/stage identity without changing the inner `SelectionError` shape. The runtime late-bind build site maps ANY builder error to `LayerStageError::FatalModule { stage_id, module_id, message }` (`crates/slicer-ir/src/stage_io.rs`), preserving stage/module identity and the exact missing map-space configuration address in `MissingModelConfig`, before any Layer invocation.
- `pub struct LayerSelectionIndex`: precomputed by `(u32 global_layer_index, ModuleId)`, with `pub fn selection_for(&self, global_layer_index: u32, module_id: &str) -> Option<&LayerSelection>` performing O(1) lookup and NO recomputation. It covers every module-backed Layer-stage module bound in the plan on every global layer, including explicitly noninvoking/empty selections. A missing bound pair is an internal-consistency fatal, not a silent default.
- `pub struct LayerSelectionIndexInput<'a> { stage_roster: &'a [slicer_schema::StageSpec], global_layers: &'a [GlobalLayer], modules: &'a [LayerSelectionModuleInput<'a>], slices: &'a [SliceIR], region_map: Option<&'a RegionMapIR>, support_plan: Option<&'a SupportPlanIR>, perimeters: &'a [PerimeterIR] }`; `stage_roster` is supplied through the public re-export `pub use slicer_schema::{StageSpec, STAGES};` in `crates/slicer-wasm-host/src/selection.rs` — runtime passes `slicer_wasm_host::selection::STAGES`, and `slicer-runtime` production never names the `slicer-schema` crate, whose edge there is a dev-dependency only, so no manifest edit is required. These public fields borrow the schema roster, all committed layers and products, and per-module static selection metadata. `pub struct LayerSelectionModuleInput<'a> { stage_id: &'a str, module_id: &'a str, claims: &'a [String], paint_semantics: Option<&'a HashSet<String>>, invocation_config: &'a ConfigView }`. Runtime supplies `Some` paint metadata from `CompiledModuleStatic::region_split_semantics()`; `None` is only the compatibility channel for an already-applied paint gate. An empty committed product slice is explicit, not a fabricated product. Perimeters available in the committed snapshot are included; later geometry is not predicted.
- `LayerSelection { stage_id: String, invoke: bool, invocation_config: Arc<ConfigView>, support_plan_presence: OptionalProductPresence, targets: Vec<SelectedLayerTarget>, slice_regions: Vec<SlicedRegion>, perimeter_configs: HashMap<OriginId, Arc<ConfigView>> }`. `OptionalProductPresence::{Absent, Present}` distinguishes unavailable support plan from present empty plan. `slice_regions` is a build-time selection snapshot for full identity/eligibility and legacy carrier context, NOT delivered payload geometry or a prediction of later geometry.
- EXISTING current shapes: `SelectedLayerTarget { source: LayerTargetSource, config: Arc<ConfigView>, held_claims: Vec<String>, authored_coloring: bool, resolved_role_tool: Option<u32> }`; `LayerTargetSource::{Model { key: RegionKey, members: Vec<RegionKey> }, SupportCarrier { entry_index: usize, object_id: String, region_id: u64, family: String, demand_ids: Vec<String>, body_ids: Vec<String>, provenance: Vec<String>, anchor_layer_index: u32 }, Raft { global_layer_index: u32 }, AnchoredStage { anchor_layer_index: u32 }}`. NEW proposed field on the EXISTING `SupportCarrier` variant: `variant_chain: Vec<(String, PaintValue)>`, copied exactly from the newly chain-bearing plan source. Model `key`/`members` store source-space identity; base config authority is resolved through a temporary exact map-space address only inside configuration resolution, not by replacing the stored key. Other variants have no model config key. Carrier object/source-region/ordered-chain fields preserve plan provenance and the wire origin, not a fabricated `RegionKey`; entry index refers to this immutable snapshot, not a persistent ID. Carrier config remains filtered invocation authority, with no coloring grant. `resolved_role_tool` remains build-time host tool authority from exact resolved `extensions["extruder"]`, never a module config read; declared-key filtering still hides undeclared extensions such as `private_probe`.
- `SelectionError::{UnknownLayerStage { stage_id: String }, MissingModelConfig { key: RegionKey }}`. Accepted stages derive from `slicer_schema::STAGES`/`stage_by_id`, `TIER_LAYER` and nonempty `wit_export`, not a duplicated stage roster. Missing exact model authority fails before invocation; optional support absence alone is not an error.
- `pub fn paint_allows_layer(declared: &HashSet<String>, slice: Option<&SliceIR>) -> bool`: public compatibility predicate used internally during index construction and by runtime's existing `module_invocation_allowed_on_layer` wrapper. Empty declarations/absent slice permit; otherwise an actual chain semantic must match. This narrow predicate does not replace indexed selection for ordinary eligibility or #04/#05.

NEW proposed public pure helper `region_map_key_for_sliced_region(global_layer_index: u32, region: &SlicedRegion) -> RegionKey` in `crates/slicer-wasm-host/src/selection.rs` factors the existing SOURCE-to-config-address conversion. It preserves object/layer/exact ordered chain while applying the existing painted/modifier address rules once. It neither reads a map nor resolves config or selection. PREPASS producers use it to capture exact config addresses from actual source slices; stored source identities remain unchanged, and indexed Layer dispatch still consumes precomputed config authority.

Existing `LayerStageInput<'a>.selection` (`crates/slicer-wasm-host/src/binding.rs`) and the committed Blackboard index remain the delivery channel. `LayerStageRunner::run_stage` (`crates/slicer-wasm-host/src/traits.rs`) keeps its signature. Production never treats `None` as permission to recompute. One NEW PRIVATE transport assembly consumes this metadata and current geometry before the dispatch split. The IR/WIT query changes described in `design.md` are coordinated contract repairs, not a second selection API; SDK stage method parameter lists remain unchanged.

Every direct `run_stage` caller must supply `Some`; `None` is confined to non-dispatching direct builder/accessor fixtures and the AC-N1 rejection control. The dispatcher signature has no test-visible discriminator permitting a legacy caller to bypass missing-selection fatal rejection.

`WasmRuntimeDispatcher::run_stage` (`crates/slicer-wasm-host/src/dispatch.rs`) receives `input.selection: Option<&LayerSelection>`; if it is `None` for a module scheduled on the current layer, this internal-consistency violation returns `LayerStageError::FatalModule` naming the scheduled stage/module, and neither the native entry nor the WASM guest is invoked or commits output.

The index is SELECTION METADATA ONLY: selected full identities, exact-key configs, held claims, merged membership, carrier/raft/anchored contexts and support presence are computed once. Payload GEOMETRY is always the CURRENT call-local product: the arena slice for the current layer (including earlier same-layer commits, notably `LayerStageCommit::Perimeters` in `crates/slicer-runtime/src/layer_executor.rs` calling `sync_perimeter_infill_areas_into_slice` in `crates/slicer-runtime/src/region_partition.rs`), current support-plan roles and current perimeter products, associated to indexed identities by full `RegionKey`/`OriginId`. Dispatch uses the index to decide WHICH identities/configs/claims to deliver, never re-derives selection, and never substitutes the build-time snapshot for current geometry. A selected identity absent from current products is delivered in its current (possibly empty) state, not as stale bytes.

#04 consumes this whole-print index on committed layers/slices/maps and explicitly available optional products. #05 uses the same `invoke`, source/context, held roles and filtered config; neither adds producer inheritance or treats `AnchoredStage` as a synthetic anchored entity. Future preparation may consume the target descriptions, not cache the current geometry as final output. Full field semantics and ordinary wiring are owned by `design.md`.

Support carrier eligibility preserves `SupportPlanEntry.global_layer_index == layer.index as i32`; `anchor_layer_index` is provenance, not this eligibility predicate. Carrier wire origin copies the plan's object/source-region ID AND exact ordered chain; empty only for a genuinely chain-empty plan source. Identity-absent exclusion and wire dedup use full `OriginId`, not the object/region pair. Same-full-origin entries retain distinct selected contexts/demands/bodies but one wire handle; different chains must not dedup. Synthetic transport never implies chain erasure, model config authority or a coloring grant. Specialist WIT query changes preserve the layer/family/anchor rules.

AC-B2 retains three EXISTING module-level private fixture helpers in `crates/slicer-wasm-host/tests/contract/shared_selection_dispatch_tdd.rs` invoked by `non_region_contexts_use_invocation_config`: `carrier_selection_delivery_fixture`, `support_rendering_positive_control` and `raft_positive_control`; they are not new exports or creation tasks.

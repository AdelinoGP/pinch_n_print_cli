# Packet Contract: shared-selection-prerequisite

Draft for the approved eight-packet queue's row 01. Internal acceptance families A (delivery repair) and B (shared targeting) are both required. Authoring changes are limited to this packet's five contracts; implementation, activation and test/gate execution are outside this authoring task.

## Goal

Repair full variant identity in ordinary native/WASM delivery and provide one reusable production selection/configuration projection for ordinary dispatch and future preparation.

## Scope Boundaries

Own full-identity delivery, variant-granular authored-color grants, and one reusable production projection for model sources, merged perimeter sources, multiple held roles, support carriers, raft and actual anchored module-stage calls. True model targets require exact `RegionKey` config; genuinely non-region targets deliberately use the resolved, declared-key-filtered invocation config supplied by `bind_module_config_view`, not missing-region fallback. Preparation capabilities/lifecycle and general ordinary error-policy repair remain separate.

## Prerequisites and Blockers

- Depends on: none.
- Unblocks: queue #04 `whole-print-input-views` and, through #04, #05 `preparation-runtime-lifecycle`, via the shared projection.
- Activation requires successful independent preflight and explicit approval. No unresolved design-choice blocker remains; status stays draft.

## Public Forward-Dependency Interface Summary

All names below are NET-NEW, public Rust contracts in `slicer-wasm-host`, implemented at `crates/slicer-wasm-host/src/selection.rs` and exposed by `pub mod selection` in `crates/slicer-wasm-host/src/lib.rs`:

- `project_layer_selection(input: LayerSelectionInput<'_>) -> Result<LayerSelection, SelectionError>`: borrowed input fields `stage_id: &str`, `layer: &GlobalLayer`, `module_id: &str`, `claims: &[String]`, `paint_semantics: Option<&HashSet<String>>`, `invocation_config: &ConfigView`, `slice: Option<&SliceIR>`, `region_map: Option<&RegionMapIR>`, `support_plan: Option<&SupportPlanIR>`, `perimeter: Option<&PerimeterIR>`. `None` paint semantics means caller has already applied the paint gate; runtime supplies `Some` from `CompiledModuleStatic::region_split_semantics()`.
- `LayerSelection { stage_id: String, invoke: bool, invocation_config: Arc<ConfigView>, support_plan_presence: OptionalProductPresence, targets: Vec<SelectedLayerTarget>, slice_regions: Vec<SlicedRegion>, perimeter_configs: HashMap<OriginId, Arc<ConfigView>> }`. `OptionalProductPresence::{Absent, Present}` distinguishes unavailable support plan from present empty plan. `slice_regions` is the selected model/perimeter-source geometry plus legacy wire carriers, not a prediction of later geometry.
- `SelectedLayerTarget { source: LayerTargetSource, config: Arc<ConfigView>, held_claims: Vec<String>, authored_coloring: bool }`; `LayerTargetSource::{Model { key: RegionKey, members: Vec<RegionKey> }, SupportCarrier { entry_index: usize, object_id: String, region_id: u64, family: String, demand_ids: Vec<String>, body_ids: Vec<String>, provenance: Vec<String>, anchor_layer_index: u32 }, Raft { global_layer_index: u32 }, AnchoredStage { anchor_layer_index: u32 }}`. Model `members` includes the base and matching merged modifier sources; config authority is the base's exact key. Other variants have no model key. Support object/region fields are plan provenance, not a fabricated key; entry index refers to this immutable input snapshot, not a persistent identifier.
- `SelectionError::{UnknownLayerStage { stage_id: String }, MissingModelConfig { key: RegionKey }}`. Accepted stages derive from `slicer_schema::STAGES`/`stage_by_id`, `TIER_LAYER` and nonempty `wit_export`, not a duplicated stage roster. Missing exact model authority fails before invocation; optional support absence alone is not an error.
- `paint_allows_layer(declared: &HashSet<String>, slice: Option<&SliceIR>) -> bool`: public compatibility predicate used internally by the projection and by runtime's existing `module_invocation_allowed_on_layer` wrapper. Empty declarations/absent slice permit; otherwise an actual chain semantic must match. This narrow predicate does not replace full projection for ordinary eligibility or #04/#05.

#04 calls this seam on committed whole-print layers/slices/maps and explicitly available optional products. #05 uses the same `invoke`, source/context, held roles and filtered config; neither adds producer inheritance or treats `AnchoredStage` as a synthetic anchored entity. Future preparation may consume the target descriptions, not cache the current geometry as final output. Full field semantics and ordinary wiring are owned by `design.md`.

Support carrier eligibility preserves `SupportPlanEntry.global_layer_index == layer.index as i32`; `anchor_layer_index` is preserved provenance, not the eligibility predicate. No export shape changes are needed for this distinction.

AC-B2 separates three executions inside its existing test: `carrier_selection_delivery_fixture`, `support_rendering_positive_control` and `raft_positive_control` (NET-NEW private fixture helpers, not exports). Only the separate support/raft rendering controls require nonempty committed paths on both native and WASM legs. The global-7/anchor-3 selection/delivery fixture must not claim nonempty support rendering: support paint exposure and `traditional-support::run_support` retain their anchor-layer checks. Native positive-control entries must emit paths, not merely observe invocation.

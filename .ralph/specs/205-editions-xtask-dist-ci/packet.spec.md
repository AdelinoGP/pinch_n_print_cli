# Packet Contract: 205-editions-xtask-dist-ci

## Goal

Give `cargo xtask dist` an edition dimension driven by packet 204's committed `dist/editions.toml` — resolving each edition into a `pnp-cli` cargo feature list, a staged external module set that is its exact complement, and a per-edition output root `target/dist/<edition>/` — with the ADR-0056 disjointness invariant enforced as a hard, unit-tested failure at both plan time and post-stage time, and a new CI job that builds and verifies the Developer and Hybrid edition artifacts (CI runs `dist` for the first time).

## Scope Boundaries

This packet rewrites `dist_command` and the `dist` arm of the `xtask` subcommand dispatcher, adds pure plan/verify helpers with in-file `#[cfg(test)]` units (`xtask` is bin-only — it has no `[lib]` target, so an `xtask/tests/*.rs` integration test could not reach them), extends `crates/pnp-cli/Cargo.toml` with the `integrated-<module>` passthrough features every non-Developer edition build needs, and adds one CI job. It does **not** integrate additional modules into `crates/slicer-integrated-modules/` (204 owns the pilot set and its parity gates), does not change dispatch, the CLI verb tree, or `--no-integrated-modules` (202/203), and does not author or edit `dist/editions.toml` itself (204 owns that file, its schema, and its evidence block).

## Acceptance Criteria

State ACs only here; `requirements.md` references their IDs.

- **AC-1. Given** `dist/editions.toml` with `developer.integrate_all = false` and an empty `developer.integrated_modules`, **when** `plan_edition(ws_root, "developer")` runs, **then** it returns a `DistPlan` whose `cargo_features` is empty, whose `integrated` set is empty, whose `external_stage` list equals — element for element, sorted — the file stems of every `build_guests::discover_guests(ws_root)` spec with `tree == GuestTree::Core` (no hardcoded module count; the assertion is derived from the same walk `dist` stages from), and whose `out_dir` ends with `target/dist/developer`. | `cargo test -p xtask dist_plan_developer_stages_every_core_module`
- **AC-2. Given** `dist/editions.toml`'s `hybrid` entry, **when** `plan_edition(ws_root, "hybrid")` runs, **then** `integrated` equals `hybrid.integrated_modules` as a set; `cargo_features` equals `integrated-<name>` for each of those names, sorted and deduplicated; `external_stage` equals the core stems from `discover_guests` minus `integrated`; `external_stage.len() + integrated.len()` equals the core stem count; and `external_stage` shares no element with `integrated`. | `cargo test -p xtask dist_plan_hybrid_derives_features_and_complement`
- **AC-3. Given** `dist/editions.toml`'s `integrated` entry with `integrate_all = true`, **when** `plan_edition(ws_root, "integrated")` runs, **then** `integrated` equals every core stem from `discover_guests`, `external_stage` is empty, and `cargo_features` has one `integrated-<name>` entry per core stem — matching ADR-0057's table row "Integrated | every core module | none". | `cargo test -p xtask dist_plan_integrated_stages_nothing_externally`
- **AC-4. Given** the `dist` subcommand argument list, **when** `parse_dist_args` is given `["--edition", "hybrid", "--debug"]` and `["--debug", "--edition", "hybrid"]`, **then** both return the same value (edition `Some("hybrid")`, debug `true`, plan_only `false`); given `["--plan"]` it returns plan_only `true`; given `[]` it returns edition `None` (resolved to `developer` by the caller) and debug `false`; and given `["--edition"]` with no value it returns `Err` naming `--edition`. | `cargo test -p xtask dist_arg_parsing_accepts_edition_and_debug_in_any_order`
- **AC-5. Given** a workspace with fresh guest WASM, **when** `cargo xtask dist --edition hybrid --debug` runs to completion and `cargo xtask dist --edition hybrid --plan` prints the resolved plan, **then** `target/dist/hybrid/modules/` contains exactly one directory per `external\t<name>` plan line and **no** directory named by any `integrated\t<name>` plan line, and `target/dist/hybrid/` contains the `pnp_cli` binary. | `sh -c 'set -e; mkdir -p target; cargo xtask dist --edition hybrid --debug >/dev/null 2>&1; cargo xtask dist --edition hybrid --plan > target/plan-hybrid.txt; bad=0; for m in $(rg "^integrated\t" target/plan-hybrid.txt | cut -f2); do if [ -e "target/dist/hybrid/modules/$m" ]; then echo "FAIL integrated module staged externally: $m"; bad=1; fi; done; staged=$(ls target/dist/hybrid/modules | wc -l); planned=$(rg -c "^external\t" target/plan-hybrid.txt); [ "$staged" = "$planned" ] || { echo "FAIL staged=$staged planned=$planned"; bad=1; }; [ -f target/dist/hybrid/pnp_cli ] || [ -f target/dist/hybrid/pnp_cli.exe ] || { echo "FAIL: no pnp_cli binary staged"; bad=1; }; [ $bad -eq 0 ] && echo PASS'`
- **AC-6. Given** `.github/workflows/ci.yml`, **when** it is inspected, **then** it declares a job named `Dist editions` that installs the `wasm32-unknown-unknown` target and `wasm-tools`, runs `cargo xtask dist --edition developer --debug` and `cargo xtask dist --edition hybrid --debug`, and runs a verification step whose failure message names the disjointness invariant — CI exercised `dist` zero times before this packet. | `sh -c 'rg -q "name: Dist editions" .github/workflows/ci.yml && rg -q -- "dist --edition developer" .github/workflows/ci.yml && rg -q -- "dist --edition hybrid" .github/workflows/ci.yml && rg -q "wasm-tools" .github/workflows/ci.yml && rg -qi "disjoint" .github/workflows/ci.yml && echo PASS'`
- **AC-7. Given** every module name in the resolved Hybrid integrated set, **when** `crates/pnp-cli/Cargo.toml` is inspected, **then** each has a passthrough cargo feature whose **body names** `slicer-integrated-modules/<name>` — the locked three-way identity (module dir == registry feature == staged stem) extended one hop to the CLI crate that is actually built by `dist`. The verification accepts only two forms, both of which assert the feature body: the canonical single-entry literal, or a whitespace-tolerant multi-entry array containing the delegation. A bare mention of `integrated-<name>` anywhere in the file (a comment, a `default` list) does **not** satisfy this AC. | `sh -c 'set -e; mkdir -p target; cargo xtask dist --edition hybrid --plan > target/plan-hybrid.txt; for m in $(rg "^integrated\t" target/plan-hybrid.txt | cut -f2); do rg -q "^integrated-$m = \[\"slicer-integrated-modules/$m\"\]" crates/pnp-cli/Cargo.toml || rg -q "^integrated-$m *= *\[[^]]*\"slicer-integrated-modules/$m\"" crates/pnp-cli/Cargo.toml || { echo "FAIL: integrated-$m absent or does not delegate to slicer-integrated-modules/$m"; exit 1; }; done; echo PASS'`
- **AC-8 (doc greps, positive and negative).** Given the doc edits below, all four positive greps pass **and** no updated surface still names the pre-edition output root: every `target/dist` occurrence in `docs/01_system_architecture.md`, `README.md`, `CLAUDE.md`, and `xtask/src/main.rs` must be a per-edition form (`target/dist/<edition>` or a literal edition name). The negative half is what catches the half-landed state where the code stages to the new root and a doc still promises the old one. | `sh -c 'rg -q -- "--edition" docs/01_system_architecture.md && rg -q "target/dist/<edition>/" docs/01_system_architecture.md && rg -q -- "--edition" README.md && rg -q -- "--edition" xtask/src/main.rs || { echo "FAIL: positive doc grep"; exit 1; }; hits=$(rg -n "target/dist" docs/01_system_architecture.md README.md CLAUDE.md xtask/src/main.rs | rg -v "target/dist/<edition>|target/dist/(developer|hybrid|integrated)"); [ -z "$hits" ] || { echo "FAIL: stale pre-edition dist root still documented:"; echo "$hits"; exit 1; }; echo PASS'`
- **AC-9. Given** at least one core module without an `integrated-<name>` feature in `crates/pnp-cli/Cargo.toml` (true at packet close, since packet 204 integrates only the pilot set), **when** `cargo xtask dist --edition integrated` runs, **then** it exits `1`; its output names `crates/pnp-cli/Cargo.toml` and the missing `integrated-` feature(s); no `target/dist/integrated/` directory is created; and no cargo build is spawned (no `Compiling ` line), proving the coverage gate runs before every build phase. The command self-guards: if the Integrated edition has become fully covered, it reports `SKIP` and defers to AC-3, so the AC does not invert when a later packet completes the integrated set. | `sh -c 'rm -rf target/dist/integrated; out=$(cargo xtask dist --edition integrated 2>&1); rc=$?; if [ "$rc" = "0" ]; then echo "SKIP: integrated edition fully covered — AC-9 vacuous, AC-3 governs"; exit 0; fi; if [ "$rc" != "1" ]; then echo "FAIL rc=$rc"; exit 1; fi; printf "%s" "$out" | rg -q "crates/pnp-cli/Cargo.toml" || { echo "FAIL: manifest not named"; exit 1; }; printf "%s" "$out" | rg -q "integrated-" || { echo "FAIL: missing feature name not listed"; exit 1; }; if printf "%s" "$out" | rg -q "Compiling "; then echo "FAIL: a build was spawned before the coverage gate"; exit 1; fi; if [ -d target/dist/integrated ]; then echo "FAIL: output dir created"; exit 1; fi; echo PASS'`

## Negative Test Cases

- **AC-N1. Given** `assert_staging_disjoint(edition, integrated_set, staged_names)` where `staged_names` contains a name that is also in `integrated_set` (the ADR-0056 shadowing case: a higher search tier silently overriding the native path via first-root-wins, negating the edition), **when** it runs, **then** it returns `Err` whose message contains the offending module name, the edition name, and the word `disjoint`; and given a staged list with no overlap it returns `Ok(())`. | `cargo test -p xtask dist_disjointness_rejects_integrated_module_in_staged_set`
- **AC-N2. Given** `verify_integrated_feature_coverage(edition, integrated_set, available_features)` where `integrated_set` contains a module for which `available_features` has no `integrated-<name>` entry, **when** it runs, **then** it returns `Err` naming that module, the edition, and `crates/pnp-cli/Cargo.toml`; **and** `preflight_edition` (the resolve → coverage → plan-time-disjointness gate) is invoked in `dist_command` strictly **before** the first `build_guests::build_command` call site, so an edition whose membership outruns the registry fails without building anything rather than producing an artifact that silently stages the un-integrated module externally. The ordering half is asserted positionally in the source and behaviorally by AC-9's "no `Compiling `" clause — the earlier grep-for-the-symbol form could not distinguish the function's own definition from a call site and is deliberately replaced. | `sh -c 'cargo test -p xtask dist_registry_coverage_rejects_missing_pnp_cli_feature || { echo "FAIL: unit test"; exit 1; }; a=$(rg -n "preflight_edition\(" xtask/src/dist.rs | rg -v "fn preflight_edition" | head -1 | cut -d: -f1); b=$(rg -n "build_guests::build_command\(" xtask/src/dist.rs | head -1 | cut -d: -f1); [ -n "$a" ] && [ -n "$b" ] || { echo "FAIL: missing call site (preflight=$a build=$b)"; exit 1; }; [ "$a" -lt "$b" ] && echo PASS || { echo "FAIL: coverage gate runs after the guest build (preflight=$a build=$b)"; exit 1; }'`
- **AC-N3. Given** an edition name absent from `dist/editions.toml`, **when** `cargo xtask dist --edition bogus` runs, **then** it exits `1`, its stderr names both `bogus` and `dist/editions.toml`, it lists the available edition keys, no `target/dist/bogus` directory is created, and no guest build or cargo build is spawned (resolution happens before any build step, so the failure is cheap). | `sh -c 'rm -rf target/dist/bogus; out=$(cargo xtask dist --edition bogus 2>&1); rc=$?; [ "$rc" = "1" ] || { echo "FAIL rc=$rc"; exit 1; }; printf "%s" "$out" | rg -q "bogus" || { echo "FAIL: name not echoed"; exit 1; }; printf "%s" "$out" | rg -q "dist/editions.toml" || { echo "FAIL: config path not named"; exit 1; }; [ ! -d target/dist/bogus ] || { echo "FAIL: dir created"; exit 1; }; echo PASS'`
- **AC-N4. Given** an unrecognized flag on the `dist` subcommand, **when** `cargo xtask dist --nope` runs, **then** it exits `2` (the existing xtask convention for a bad flag, matching the `build-guests` / `gen-config-docs` arms) and prints `USAGE`, and `cargo xtask dist --edition` (missing value) also exits `2`. | `sh -c 'cargo xtask dist --nope >/dev/null 2>&1; a=$?; cargo xtask dist --edition >/dev/null 2>&1; b=$?; [ "$a" = "2" ] && [ "$b" = "2" ] && echo PASS || { echo "FAIL a=$a b=$b"; exit 1; }'`

# Packet Contract: 187-custom-gcode-injection-registry

## Goal

Replace `machine-gcode-emit`'s two hand-inlined template reads with a real injection-point registry — a `const INJECTION_POINTS` table pairing each custom-G-code config key with the stream site at which its resolved template is spliced, plus a per-site variable set — and use it to land every **layer-scoped** OrcaSlicer injection point that PnP's pipeline can reach today: `before_layer_change_gcode`, `time_lapse_gcode` and `layer_change_gcode`, spliced immediately after the host-emitted `;LAYER_CHANGE` / `;Z:` / `;HEIGHT:` marker triple, in that canonical order, with `layer_num`, `layer_z` and `max_layer_z` resolvable at those sites and at `machine_end_gcode` but **not** at `machine_start_gcode`.

## Scope Boundaries

Touches `modules/core-modules/machine-gcode-emit/src/lib.rs` (the registry, the site walk over `commands`, and the per-site variable lookup), `modules/core-modules/machine-gcode-emit/machine-gcode-emit.toml` (three new string keys), and the two test files that pin the module's behaviour. No host crate changes: the `;LAYER_CHANGE` / `;Z:<z>` / `;HEIGHT:<h>` triple is already emitted by `DefaultGCodeEmitter` in `crates/slicer-gcode/src/emit.rs` and already pinned by `crates/slicer-gcode/tests/golden_emit_tdd.rs`, so the site markers are an existing contract this packet consumes rather than one it creates. Toolchange-scoped and extrusion-role-scoped points, and the five points PnP cannot reach at all, are packet 188.

## Prerequisites and Blockers

- Depends on: **`186-custom-gcode-placeholder-engine` (TASK-305)**, hard. This packet routes three more templates through `substitute_placeholders`, and it relies on 186's `(String, Vec<String>)` return shape, its `ERR_UNRESOLVED_PLACEHOLDER` constant, and its collect-all-then-fail-once rule to make AC-N1 expressible. Implementing 187 first would either duplicate that work or reintroduce silent passthrough at three new sites.
- Unblocks: `188-custom-gcode-conditional-points` (TASK-307), which adds `InjectionSite` variants for toolchange and extrusion-role sites to the same table.
- Activation blockers: none technical. `140_lightning-module-rewrite` is the only `active` packet; this stays `draft` until that clears **and** until 186 is `implemented`. **Packets 181-186 are all `status: draft`** — nothing they file has landed; no claim here may cite any of them as done.

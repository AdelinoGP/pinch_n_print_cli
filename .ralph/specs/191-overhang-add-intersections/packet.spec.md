# Packet Contract: 191-overhang-add-intersections

## Goal

Port canonical `estimate_points_properties`' (`GCode/ExtrusionProcessor.hpp`) mid-segment vertex insertion into `modules/core-modules/overhang-classifier-default/src/lib.rs`: both the **threshold-crossing** branch (where a segment crosses the previous-layer boundary offset, insert one synthetic vertex per crossing carrying `distance = boundary_offset`, filtered by the two-sided `min_spacing = flow_width * 0.25` test) and the **segmentation** branch (up to two interior vertices at `t0`/`t1`, gated on `min_distance > 0 && (|curr.distance| > min_distance || |next.distance| > min_distance) && line_len >= 2mm` or on `min_distance <= 0 && line_len > 4mm`), with `min_distance` supplied by canonical's `smallest_distance_with_lower_speed` derived from packet 190's `speed_sections` table and its `!found ⇒ -1.f` fallback — carried into the IR by a new `EntityMutation::SetPathPoints(Vec<Point3WithWidth>)` geometry channel, and closing `DEV-009`.

## Scope Boundaries

Two surfaces: the guest module that computes the insertions (`modules/core-modules/overhang-classifier-default/src/lib.rs` plus its two test files and the TRIPWIRE mirror in `crates/slicer-runtime/tests/integration/overhang_classifier_refactor_regression_tdd.rs`), and the additive geometry-mutation channel it needs (`crates/slicer-schema/wit/deps/finalization-layer-finalization/finalization-layer-finalization.wit`, `slicer_sdk::traits::EntityMutation` and its `apply_to` arm, `slicer_wasm_host::host::WitEntityMutation`, the `dispatch.rs` and `slicer-macros` translations). No new config key, no emitter change, no prepass change, and no re-banding of `annotate_overhangs`' four concentric `overhang_quartile` bands (`BAND_BOUNDARY_MULTIPLIERS` in `crates/slicer-core/src/algos/overhang_annotation.rs`). **Note the framing this packet set settled:** the restoration of canonical's six `{90, 75, 50, 25, 13, 0}` overlap levels as emission-time *speed sections* belongs to packet 190 and is **settled** there — the maintainer ruled option (C) and `ADR-0053` §"What option (C) does NOT change" authorises the restoration explicitly (an earlier revision of this line called it "a live scope question" under `190/design.md` §Open Questions `[BLOCK-1b]`; that block is resolved). It is **not** the same object as the four quartile bands, and neither this packet nor 190 changes those bands.

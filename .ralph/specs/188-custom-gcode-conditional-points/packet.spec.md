# Packet Contract: 188-custom-gcode-conditional-points

## Goal

Land every remaining OrcaSlicer custom-G-code injection point that PnP's pipeline can actually reach — the toolchange trio `filament_end_gcode` / `change_filament_gcode` / `filament_start_gcode`, spliced around each `GCodeCommand::ToolChange` in canonical `GCode::set_extruder` order, and the extrusion-role trio `change_extrusion_role_gcode` / `filament_change_extrusion_role_gcode` / `process_change_extrusion_role_gcode`, spliced immediately before each host-emitted `;TYPE:` marker — by extending packet 187's `InjectionSite` enum and `INJECTION_POINTS` table rather than forking them; and record the five points PnP cannot reach today as residual deviations with the measured evidence for each, rather than faking them.

## Scope Boundaries

Touches `modules/core-modules/machine-gcode-emit/src/lib.rs` (four new `InjectionSite` variants, six new table entries, the toolchange and role site walks, and their per-site variable sets), `modules/core-modules/machine-gcode-emit/machine-gcode-emit.toml` (six new string keys, taking the schema from eight to fourteen), and three test files. No host crate change: `GCodeCommand::ToolChange` and the `;TYPE:<label>` `Raw` markers are both already produced by `DefaultGCodeEmitter` in `crates/slicer-gcode/src/emit.rs`. `file_start_gcode`, `wrapping_detection_gcode`, `machine_pause_gcode`, `template_custom_gcode` and `printing_by_object_gcode` are **not implemented** — each is unreachable from `PostPass::GCodePostProcess` for a reason measured against this tree and recorded in a residual row.
